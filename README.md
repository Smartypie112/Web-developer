# Web-developer

## GitHub Pages

The site entry page is `index.html` in the repository root. To publish it with
GitHub Pages, select the `main` branch and `/ (root)` as the deployment source
in the repository's Pages settings.

## Project files

- `index.html`, `index-1.html`, and `vid.html` are the pages served from the root.
- `assets/css/` contains the site's stylesheet.
- `assets/images/` contains image and animation files.
- `assets/videos/` contains the project showcase videos.
